# ✅ Enable GitHub Pages - Final Step!

Your code is now on GitHub! 🎉

## Enable GitHub Pages:

1. **Go to your repository**: https://github.com/AmineLaz10/portfolio

2. **Click "Settings"** (top menu bar)

3. **Click "Pages"** (left sidebar, under "Code and automation")

4. **Under "Source"**:
   - **Branch**: Select `main`
   - **Folder**: Select `/ (root)`

5. **Click "Save"** (green button)

6. **Wait 1-2 minutes** for GitHub to build your site

7. **Visit your live site**: 
   - **https://aminelazrak.github.io/portfolio**

---

## 🎯 Your Site URL:

Since your repository is named `portfolio`, your site will be at:
**https://aminelazrak.github.io/portfolio**

---

## 💡 Want a Cleaner URL? (Optional)

If you want your site at just `https://aminelazrak.github.io` (without `/portfolio`):

1. Go to repository **Settings** → **General**
2. Scroll to bottom → **"Danger Zone"**
3. Click **"Change repository name"**
4. Rename to: `aminelazrak.github.io`
5. GitHub Pages will automatically update!
